# 議事録生成プロンプト定義

このディレクトリは、議事録生成に使用されるプロンプトを管理します。
議事録の種類（例: 会議、授業）に応じてサブディレクトリを作成し、その中にプロンプトファイルを格納します。

## ディレクトリ構造

- `meeting/`: 一般的な会議用のプロンプト
- `lecture/`: 授業や講義用のプロンプト
- `(その他)/`: 将来的な拡張（例: `interview/`, `seminar/`）

各サブディレクトリには、目的に応じたMarkdown形式のプロンプトファイルを配置します。

- `detailed_minutes.md`: 詳細な議事録を生成するためのプロンプト
- `summary_minutes.md`: 要約版の議事録を生成するためのプロンプト
- `action_items.md`: アクションアイテム（TODO）を抽出するためのプロンプト

## プロンプトの選択

使用するプロンプトは、`settings.json` の `minutes_type` 設定によって決定されます。
例えば、`"minutes_type": "lecture"` と設定されている場合、`lecture/` ディレクトリ内のプロンプトが使用されます。

## プロンプトファイルの形式

プロンプトファイルは、`src/utils/prompt_loader.py` によって解析されるため、指定された形式に従う必要があります。
詳細については、ルートの `README.md` または `prompt_loader.py` のドキュメントを参照してください。
