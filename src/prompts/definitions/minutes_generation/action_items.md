# アクションアイテム抽出プロンプト

## 概要
会議の文字起こし結果から具体的なアクションアイテム（タスク・課題・宿題）を抽出し、構造化して整理するためのプロンプトです。

## パラメータ
- `{transcription}`: 文字起こし結果
- `{meeting_context}`: 会議の種類や文脈（例: "プロジェクト会議", "授業", "研修"）
- `{language}`: 出力言語（例: "ja", "en"）
- `{include_deadlines}`: 期限情報を含めるかどうか（true/false）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下の文字起こし結果からアクションアイテム（課題・タスク・宿題）を抽出してください。

**言語**: {language}
**会議種類**: {meeting_context}
**期限情報の抽出**: {include_deadlines}

**アクションアイテム抽出指示事項**:

### 抽出対象
以下のような内容をアクションアイテムとして抽出してください：
- 明確に指示された課題や宿題
- 「〜してください」「〜をお願いします」などの依頼事項
- 「次回までに〜」「〜を準備する」などのタスク
- 決定事項に基づく実行すべき作業
- フォローアップが必要な事項

### 出力形式
以下の構造化された形式で出力してください：

```
# アクションアイテム一覧

## 緊急度：高
### **アクション1:**
* **内容:** 具体的なタスク内容
* **担当者:** 責任者名（不明な場合は「未指定」）
* **期限:** 完了予定日（不明な場合は「未指定」）
* **詳細:** 補足説明や背景情報
* **関連議題:** 関連する議論のトピック

### **アクション2:**
* 同様の形式で記載

## 緊急度：中
### **アクション3:**
* 同様の形式で記載

## 緊急度：低
### **アクション4:**
* 同様の形式で記載

## フォローアップ事項
### **フォローアップ1:**
* **内容:** 継続的に確認が必要な事項
* **担当者:** 責任者名
* **次回確認日:** 確認予定日

## 継続課題
* 長期的に取り組むべき課題
* 次回会議で再議論する事項
```

### 抽出の詳細要件
- **明確性**: 曖昧な表現は避け、具体的なアクションを記載
- **実行可能性**: 実際に実行可能な形で記述
- **完全性**: 重要なアクションアイテムを見落とさない
- **優先度**: 緊急度や重要度に応じて分類

### 担当者の特定
- 明確に指名された場合：その人の名前を記載
- 役職で指定された場合：「〜担当者」として記載
- 不明な場合：「未指定」として記載
- 複数人の場合：全員の名前を記載

### 期限の特定
- 明確な日付：「2024年8月15日」
- 相対的な期限：「次回会議まで」「来週末まで」
- 不明な場合：「未指定」として記載
- 継続的な作業：「継続」として記載

### 緊急度の判定基準
- **高**: 明確な期限があり、他の作業に影響する重要なタスク
- **中**: 期限があるが、ある程度の余裕があるタスク
- **低**: 期限が不明確、または長期的なタスク

{custom_instructions}

**文字起こし結果:**
{transcription}

## 使用例
```
入力: "田中さん、来週までにAPI設計書を作成してください。また、佐藤さんはデータベース設計を次回会議までにお願いします。"

出力:
# アクションアイテム一覧

## 緊急度：高
### **API設計書作成:**
* **内容:** API設計書の作成
* **担当者:** 田中さん
* **期限:** 来週まで
* **詳細:** プロジェクトの次フェーズに必要
* **関連議題:** システム設計

### **データベース設計:**
* **内容:** データベース設計の実施
* **担当者:** 佐藤さん
* **期限:** 次回会議まで
* **詳細:** API設計と連携が必要
* **関連議題:** システム設計
```

## 注意事項
- 単なる情報共有や報告は除外してください
- 具体的なアクションが伴わない議論は含めないでください
- 既に完了している事項は除外してください
- 曖昧な表現は可能な限り具体化してください
- 重複するアクションアイテムは統合してください
