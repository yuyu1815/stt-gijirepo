# 要約議事録生成プロンプト

## 概要
文字起こし結果から簡潔で要点を絞った要約議事録を生成するためのプロンプトです。重要なポイントと決定事項に焦点を当てた読みやすい議事録を作成します。

## パラメータ
- `{transcription}`: 文字起こし結果
- `{meeting_info}`: 会議情報（日時、参加者、議題など）
- `{language}`: 出力言語（例: "ja", "en"）
- `{max_length}`: 最大文字数（オプション）
- `{focus_areas}`: 重点的に記録すべき領域（オプション）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下の文字起こし結果から簡潔な要約議事録を作成してください。

**言語**: {language}
**会議情報**: {meeting_info}
**最大文字数**: {max_length}
**重点領域**: {focus_areas}

**要約議事録作成指示事項**:

### 基本構造
以下の簡潔な構造に従って議事録を作成してください：

```
# 議事録要約：{meeting_title}

## 基本情報
* **日時:** {datetime}
* **参加者:** {key_participants}
* **議題:** {main_agenda}

## 主要な議論・決定事項
### {key_topic_1}
* 重要なポイントを3-5点で簡潔に記載
* 決定事項があれば明確に記載

### {key_topic_2}
* 同様に簡潔に記載

## アクションアイテム
* **{action_1}** - 担当者：{person}, 期限：{deadline}
* **{action_2}** - 担当者：{person}, 期限：{deadline}

## 次回予定
* {next_meeting_info}
```

### 要約の要件
- **簡潔性**: 冗長な表現を避け、要点のみを記載
- **重要度**: 重要な決定事項と議論を優先的に記録
- **明確性**: 曖昧な表現を避け、具体的に記述
- **完結性**: 読み手が会議の全体像を把握できる内容

### 記録の優先順位
1. **決定事項**: 会議で決定された具体的な事項
2. **アクションアイテム**: 誰が何をいつまでに行うか
3. **重要な議論**: 今後に影響する重要な議論内容
4. **次回予定**: 継続事項や次回会議の予定

### 省略すべき内容
- 「了解しました」「ありがとうございます」などの定型的な応答
- 議論の詳細な経緯（結論のみ記載）
- 重要でない雑談や脱線した話題
- 重複する内容や冗長な説明

### 技術内容の要約
技術的な内容が含まれる場合：
```
### システム設計の決定
* データベース：PostgreSQLを採用
* API設計：RESTful APIで実装
* 主要な懸念事項：パフォーマンス最適化が必要
```

{custom_instructions}

**文字起こし結果:**
{transcription}

## 使用例
```
入力: 長時間の技術会議の文字起こし（2時間分）
出力:
# 議事録要約：システム設計会議

## 基本情報
* **日時:** 2024年7月21日 14:00-16:00
* **参加者:** 田中（PM）、佐藤（エンジニア）、山田（デザイナー）
* **議題:** 新システムの技術選定

## 主要な議論・決定事項
### 技術スタック
* フロントエンド：React + TypeScript
* バックエンド：Node.js + Express
* データベース：PostgreSQL

### 開発スケジュール
* 設計フェーズ：8月末まで
* 開発フェーズ：12月末まで
* テストフェーズ：1月末まで

## アクションアイテム
* **詳細設計書作成** - 担当者：佐藤, 期限：8月15日
* **UI/UXモックアップ** - 担当者：山田, 期限：8月20日

## 次回予定
* 8月25日 14:00 - 設計レビュー会議
```

## 注意事項
- 文字数制限がある場合は、重要度に応じて内容を調整してください
- 専門用語は必要に応じて簡潔な説明を追加してください
- 決定事項は曖昧さを残さず明確に記録してください
- 参加者の発言意図を正確に反映してください
