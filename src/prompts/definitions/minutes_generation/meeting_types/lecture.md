# 授業・講義用議事録生成プロンプト

## 概要
授業や講義の文字起こし結果から、学習内容を体系的に整理した議事録を生成するためのプロンプトです。教育的な観点から重要な情報を構造化して記録します。

## パラメータ
- `{transcription}`: 文字起こし結果
- `{class_name}`: 授業名・科目名
- `{class_change_note}`: 授業の変更点や特記事項（オプション）
- `{datetime}`: 開催日時
- `{teacher}`: 講師名
- `{language}`: 出力言語（例: "ja", "en"）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下は授業の文字起こしです。この文字起こしから授業議事録を作成してください。

**授業名**: {class_name}
**日時**: {datetime}
**講師**: {teacher}
**言語**: {language}
**特記事項**: {class_change_note}

**授業議事録作成指示事項**:

### 基本構造
以下の構造に従って授業議事録を作成してください：

```
# 議事録：{class_name} {class_change_note}

## 1. 基本情報
* **開催日時:** {datetime}
* **講師:** {teacher}
* **出席者/対象者:** [情報があれば記載]
* **記録担当:** AI Assistant

## 2. 授業内容
### {topic_1}
* 授業の主要なトピックや説明内容を時間経過やテーマごとに整理
* 重要な概念や理論の説明を分かりやすく記載
* 実演やデモンストレーションの内容も詳細に記録
* コードや技術的な内容は適切にフォーマット

### {topic_2}
* 同様に記録...

## 3. 要約（キーポイント）
* この授業で最も重要だったポイントを3～5点程度で簡潔にまとめ
* 学習した主要な概念、結論、重要な発見を明確に記載
* 次回授業への接続点やネクストステップを示す

## 4. 課題・宿題
### **課題1:**
* **内容:** 課題の内容を具体的に記述
* **提出期限:** YYYY年MM月DD日 or 次回授業時 など
* **提出方法:** オンライン提出、紙で提出 など
* **備考:** 補足事項があれば記載

### **課題2:**
* 同様に記載...

## 5. 質疑応答
### **質問1:**
* **質問者:** 学生A（または匿名）
* **質問内容:** 具体的な質問内容
* **回答:** 講師の回答内容
* **補足:** 追加説明があれば記載

## 6. 専門用語集
### **{term_1}:**
授業内で使用された専門用語や重要なキーワードの説明

### **{term_2}:**
同様に説明...

## 7. 参考資料・リンク
* 授業中に紹介された参考書籍、ウェブサイト、論文など
* 追加学習のための推奨資料
```

### 記録の詳細要件
- **教育的価値**: 学習者にとって有益な情報を優先的に記録
- **理解促進**: 複雑な概念は分かりやすく説明を追加
- **実践的内容**: 実習やデモの手順も詳細に記録
- **継続性**: 前回授業との関連性や次回への接続を意識

### コード・技術内容の記録
プログラミングや技術的な内容が含まれる場合：
```
講師：このコードを見てください
[映像: 画面にPythonコードが表示]
```python
def example_function(param):
    """
    この関数は...という処理を行います
    """
    return param * 2
```
**解説**: この関数は引数を2倍にして返す簡単な例です。
```

### 質疑応答の記録
- 学生からの質問は匿名化して記録
- 重要な質問と回答は詳細に記録
- 理解を深める補足説明も含める

### 除外すべき内容
- 「了解しました」などの不必要な相槌
- 授業と関係のない雑談や脱線した内容
- 別の授業と思われる内容
- 個人的な情報や不適切な発言

{custom_instructions}

**文字起こし結果:**
{transcription}

## 使用例
```
入力: "今日はPythonの基本について学習します。まず変数の概念から説明しましょう..."

出力:
# 議事録：Python基礎講座 第1回

## 1. 基本情報
* **開催日時:** 2024年7月21日 14:00-16:00
* **講師:** 田中先生
* **対象者:** プログラミング初心者
* **記録担当:** AI Assistant

## 2. 授業内容
### 変数の概念
* プログラミングにおける変数の役割と重要性
* 変数名の命名規則とベストプラクティス
* 実際のコード例を用いた説明

### データ型の基礎
* 文字列、数値、真偽値の違いと使い分け
* 型変換の方法と注意点
...
```

## 注意事項
- 学習者の理解を促進する内容を優先してください
- 専門用語は必ず説明を追加してください
- 実習内容は再現可能な形で記録してください
- 課題や宿題は明確で具体的に記載してください
- 授業の流れと論理構造を保持してください
