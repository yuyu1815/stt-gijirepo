# 詳細議事録生成プロンプト

## 概要
文字起こし結果から詳細で構造化された議事録を生成するためのプロンプトです。会議の内容を体系的に整理し、重要な情報を漏れなく記録します。

## パラメータ
- `{transcription}`: 文字起こし結果
- `{meeting_info}`: 会議情報（日時、参加者、議題など）
- `{language}`: 出力言語（例: "ja", "en"）
- `{format_type}`: 議事録の形式（例: "detailed", "summary"）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下の文字起こし結果から詳細な議事録を作成してください。

**言語**: {language}
**形式**: {format_type}
**会議情報**: {meeting_info}

**議事録作成指示事項**:

### 基本構造
以下の構造に従って議事録を作成してください：

```
# 議事録：{meeting_title}

## 1. 基本情報
* **開催日時:** {datetime}
* **場所/形式:** {location}
* **参加者:** {participants}
* **議題:** {agenda}
* **記録担当:** AI Assistant

## 2. 議事内容
### {topic_1}
* 主要な議論点や決定事項を時系列で記録
* 重要な発言や提案を具体的に記載
* コードや技術的な内容は適切にフォーマット

### {topic_2}
* 同様に記録...

## 3. 決定事項・合意内容
* 会議で決定された事項を明確に記載
* 合意に至った経緯も簡潔に説明

## 4. アクションアイテム・課題
### **課題1:**
* **内容:** 具体的な課題内容
* **担当者:** 責任者名
* **期限:** 完了予定日
* **備考:** 補足事項

## 5. 次回予定・継続事項
* 次回会議の予定
* 継続して議論すべき事項

## 6. 専門用語・重要キーワード
### **{term_1}:**
会議の文脈に基づいた用語の説明

### **{term_2}:**
同様に説明...
```

### 記録の詳細要件
- **正確性**: 発言内容を正確に反映してください
- **構造化**: 議論の流れが分かるよう論理的に整理してください
- **完全性**: 重要な情報を漏らさないよう注意してください
- **簡潔性**: 冗長な表現は避け、要点を明確にしてください

### コード・技術内容の記録
コードや技術的な内容が含まれる場合：
```
参加者A：このAPIの実装について説明します
```python
def api_function():
    return {"status": "success"}
```
上記のコードは...（説明）
```

### 品質保証
- 「了解しました」などの不要な相槌は省略してください
- 議論の本質的な内容に焦点を当ててください
- 発言者の意図を正確に反映してください
- 専門用語は文脈に応じて説明を追加してください

{custom_instructions}

**文字起こし結果:**
{transcription}

## 使用例
```
入力: "Aさん：今日はプロジェクトの進捗について話し合いましょう。Bさん：はい、まずAPIの実装状況ですが..."
出力:
# 議事録：プロジェクト進捗会議

## 1. 基本情報
* **開催日時:** 2024年XX月XX日
* **参加者:** Aさん（司会）、Bさん（開発担当）
* **議題:** プロジェクト進捗確認

## 2. 議事内容
### API実装状況
* Bさんより実装状況の報告
* 現在の進捗と課題について議論
...
```

## 注意事項
- 会議の種類に応じて構造を調整してください
- 重要な決定事項は必ず記録してください
- 技術的な詳細も適切に記録してください
- 参加者のプライバシーに配慮してください
