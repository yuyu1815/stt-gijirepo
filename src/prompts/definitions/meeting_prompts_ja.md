# 詳細議事録生成プロンプト

## 概要
文字起こし結果から詳細で構造化された議事録を生成するためのプロンプトです。会議の内容を体系的に整理し、重要な情報を漏れなく記録します。

## パラメータ
- `{transcription}`: 文字起こし結果
- `{meeting_info}`: 会議情報（日時、参加者、議題など）
- `{language}`: 出力言語（例: "ja", "en"）
- `{format_type}`: 議事録の形式（例: "detailed", "summary"）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下の文字起こし結果から詳細な議事録を作成してください。

**言語**: {language}
**形式**: {format_type}
**会議情報**: {meeting_info}

**議事録作成指示事項**:

### 基本構造
以下の構造に従って議事録を作成してください：

```
# 議事録：{meeting_title}

## 1. 基本情報
* **開催日時:** {datetime}
* **場所/形式:** {location}
* **参加者:** {participants}
* **議題:** {agenda}
* **記録担当:** AI Assistant

## 2. 議事内容
### {topic_1}
* 主要な議論点や決定事項を時系列で記録
* 重要な発言や提案を具体的に記載
* コードや技術的な内容は適切にフォーマット

### {topic_2}
* 同様に記録...

## 3. 決定事項・合意内容
* 会議で決定された事項を明確に記載
* 合意に至った経緯も簡潔に説明

## 4. アクションアイテム・課題
### **課題1:**
* **内容:** 具体的な課題内容
* **担当者:** 責任者名
* **期限:** 完了予定日
* **備考:** 補足事項

## 5. 次回予定・継続事項
* 次回会議の予定
* 継続して議論すべき事項

## 6. 専門用語・重要キーワード
### **{term_1}:**
会議の文脈に基づいた用語の説明

### **{term_2}:**
同様に説明...
```

### 記録の詳細要件
- **正確性**: 発言内容を正確に反映してください
- **構造化**: 議論の流れが分かるよう論理的に整理してください
- **完全性**: 重要な情報を漏らさないよう注意してください
- **簡潔性**: 冗長な表現は避け、要点を明確にしてください

### コード・技術内容の記録
コードや技術的な内容が含まれる場合：
```
参加者A：このAPIの実装について説明します
```python
def api_function():
    return {"status": "success"}
```
上記のコードは...（説明）
```

### 品質保証
- 「了解しました」などの不要な相槌は省略してください
- 議論の本質的な内容に焦点を当ててください
- 発言者の意図を正確に反映してください
- 専門用語は文脈に応じて説明を追加してください

# アクションアイテム抽出プロンプト

## 概要
会議の文字起こしや議事録から、アクションアイテム（タスク、課題、宿題など）を抽出し、構造化するためのプロンプトです。誰が何をいつまでに行うべきかを明確にします。

## パラメータ
- `{content}`: 文字起こしまたは議事録の内容
- `{content_type}`: 入力コンテンツの種類（"transcription", "minutes"）
- `{language}`: 出力言語（例: "ja", "en"）
- `{participants}`: 参加者リスト（オプション）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下の{content_type}からアクションアイテム（タスク、課題、宿題など）を抽出し、構造化してください。

**言語**: {language}
**参加者**: {participants}

**アクションアイテム抽出指示事項**:

### 抽出対象
以下のような表現を含むアクションアイテムを抽出してください：
- 「〜してください」「〜する必要があります」などの依頼・指示表現
- 「〜します」「〜やります」などの約束・コミットメント表現
- 「〜すべきです」「〜が重要です」などの推奨・提案表現
- 「次回までに〜」「期限は〜」などの期限付きタスク表現
- 「担当は〜」「〜さんお願いします」などの担当者指定表現

### 抽出項目
各アクションアイテムについて、以下の情報を抽出してください：
- **内容**: タスクの具体的な内容
- **担当者**: 誰が担当するか
- **期限**: いつまでに完了すべきか
- **優先度**: 明示されている場合のみ（高/中/低）
- **依頼者**: 誰がタスクを依頼したか
- **関連トピック**: どの議題に関連するか
- **備考**: その他の重要な情報

### 出力形式
以下の形式でアクションアイテムを出力してください：

```
# アクションアイテム一覧

## 1. {アクションアイテムの簡潔なタイトル}
* **内容:** 具体的なタスク内容
* **担当者:** 担当者名
* **期限:** 期限（日付または相対的な期間）
* **優先度:** 高/中/低（明示されている場合のみ）
* **依頼者:** 依頼者名
* **関連トピック:** 関連する議題
* **備考:** 補足情報

## 2. {アクションアイテムの簡潔なタイトル}
* ...
```

### 処理ルール
- 明示的に指定されていない場合は、文脈から担当者や期限を推測してください
- 推測した情報には「（推測）」と明記してください
- 同じ内容のアクションアイテムは統合してください
- 優先度が明示されていない場合は記載しないでください
- 内容が曖昧な場合は、可能な限り具体化してください
- 期限が相対的（「来週まで」など）の場合は、そのまま記載してください

{custom_instructions}

**入力内容:**
{content}
</minutes_generation_action_items>

# 要約議事録生成プロンプト

## 概要
文字起こし結果から簡潔で要点を押さえた要約議事録を生成するためのプロンプトです。長い会議内容を短時間で把握できるよう、重要なポイントのみを抽出します。

## パラメータ
- `{transcription}`: 文字起こし結果
- `{meeting_info}`: 会議情報（日時、参加者、議題など）
- `{language}`: 出力言語（例: "ja", "en"）
- `{max_length}`: 最大文字数または単語数（オプション）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下の文字起こし結果から簡潔な要約議事録を作成してください。

**言語**: {language}
**最大長**: {max_length}
**会議情報**: {meeting_info}

**要約議事録作成指示事項**:

### 基本構造
以下の構造に従って要約議事録を作成してください：

```
# 要約議事録：{meeting_title}

## 基本情報
* **開催日時:** {datetime}
* **参加者:** {participants}
* **議題:** {agenda}

## 会議の目的
会議の主な目的を1-2文で簡潔に説明

## 主要ポイント
1. 最も重要なポイント
2. 2番目に重要なポイント
3. 3番目に重要なポイント
...

## 決定事項
* 決定事項1
* 決定事項2
...

## アクションアイテム
* 担当者A: タスク内容（期限）
* 担当者B: タスク内容（期限）
...

## 次回予定
次回会議の日時と主な議題
```

### 要約の詳細要件
- **簡潔性**: 冗長な表現を避け、要点のみを記載してください
- **重要度**: 最も重要な情報を優先的に含めてください
- **網羅性**: 主要な議題と決定事項はすべて含めてください
- **客観性**: 個人的な意見を混ぜず、客観的に記録してください

### 要約テクニック
- 繰り返しの議論は一つにまとめてください
- 細かい説明や例示は省略してください
- 決定に至らなかった議論は簡潔に結論のみ記載してください
- 技術的な詳細は必要最小限にとどめてください

{custom_instructions}

**文字起こし結果:**
{transcription}

# 会議動画解析プロンプト

## 概要
会議の動画を解析し、参加者の関与度、議論の流れ、非言語コミュニケーションなどを評価するためのプロンプトです。会議の効率性や有効性を向上させるための洞察を提供します。

## パラメータ
- `{video_info}`: 動画の基本情報（解像度、長さ、フォーマットなど）
- `{meeting_type}`: 会議の種類（"brainstorming", "decision_making", "status_update"など）
- `{participant_count}`: 参加者の数
- `{analysis_focus}`: 分析の焦点（"engagement", "dynamics", "efficiency"など）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下の会議動画を解析し、会議の効率性と有効性を評価してください。

**動画情報**: {video_info}
**会議種類**: {meeting_type}
**参加者数**: {participant_count}
**分析焦点**: {analysis_focus}

**会議動画解析指示事項**:

### 解析項目

#### 1. 参加者の関与度評価
- **発言バランス**: 各参加者の発言時間と頻度
- **積極的参加**: 自発的な発言や質問の頻度
- **注意力**: 集中度や注意散漫の兆候
- **反応**: 他者の発言への反応や応答

#### 2. 会議ダイナミクス分析
- **議論の流れ**: 話題の移行と議論の構造
- **意思決定プロセス**: 決定に至るプロセスの効率性
- **対立と解決**: 意見の相違とその解決方法
- **ファシリテーション**: 進行役の効果的な介入

#### 3. 非言語コミュニケーション
- **ボディランゲージ**: 姿勢、ジェスチャー、表情
- **声のトーン**: 声の調子、速さ、音量の変化
- **視線**: アイコンタクトのパターン
- **空間利用**: 参加者の配置と空間の使い方

#### 4. 会議効率性評価
- **時間管理**: 議題ごとの時間配分と全体の時間効率
- **目標達成**: 会議の目標に対する達成度
- **脱線**: 議題から外れた議論の頻度と影響
- **技術活用**: プレゼンテーションツールなどの効果的な使用
