# チャンク文字起こしプロンプト

## 概要
長時間の音声ファイルを分割処理する際に使用するプロンプトです。音声の連続性と文脈を保ちながら、部分的な文字起こしを行います。

## パラメータ
- `{chunk_index}`: 現在のチャンク番号（1から開始）
- `{total_chunks}`: 全チャンク数
- `{language}`: 音声の言語（例: "ja", "en"）
- `{previous_context}`: 前のチャンクの最後の部分（オプション）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下は長時間音声の一部（チャンク {chunk_index}/{total_chunks}）です。この部分を正確に文字起こししてください。

**言語**: {language}
**チャンク情報**: {chunk_index}/{total_chunks}

**チャンク文字起こし指示事項**:

### 基本要件
- この音声チャンクの内容を正確に文字起こししてください
- 話者が複数いる場合は、話者を区別して記録してください
- 専門用語や固有名詞も可能な限り正確に書き起こしてください
- 音声が不明瞭な場合は[不明瞭]と記載してください

### チャンク処理特有の要件
- チャンクの開始部分で文が途切れている場合は、[チャンク開始]として記録してください
- チャンクの終了部分で文が途切れている場合は、[チャンク終了]として記録してください
- 前のチャンクとの連続性を意識して文字起こししてください
- 話者の変更があった場合は明確に記録してください

### 文脈の継続性
{previous_context}

上記の文脈を参考に、自然な流れで文字起こしを開始してください。

### 品質保証
- チャンク境界での文の切れ目を適切に処理してください
- 全体の文脈を損なわないよう注意してください
- 重複や欠落がないよう確認してください

{custom_instructions}

## 使用例
```
チャンク 2/5の場合:
前の文脈: "...システムの設計について説明します"
現在のチャンク音声: "まず最初にデータベースの構造ですが..."
出力: "発表者：まず最初にデータベースの構造ですが..."

チャンク境界で途切れる場合:
音声: "このAPIの実装に関して..."（途切れ）
出力: "開発者：このAPIの実装に関して[チャンク終了]"
```

## 注意事項
- チャンク間の連続性を保つことを最優先としてください
- 文の途切れは自然に処理し、無理に補完しないでください
- 話者の識別は前のチャンクとの一貫性を保ってください
- 重要な情報の欠落を防ぐため、境界部分は特に注意深く処理してください
