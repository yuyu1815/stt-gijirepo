# 動画文字起こしプロンプト

## 概要
動画ファイルから音声と映像情報の両方を活用して文字起こしを行うためのプロンプトです。画面に表示される内容やコード、図表なども含めて記録します。

## パラメータ
- `{language}`: 音声の言語（例: "ja", "en"）
- `{video_context}`: 動画の種類や文脈（例: "プログラミング講座", "プレゼンテーション"）
- `{include_visual_info}`: 映像情報を含めるかどうか（true/false）
- `{custom_instructions}`: カスタム指示（オプション）

## プロンプト本文

以下の動画ファイルを音声と映像の両方を考慮して文字起こししてください。

**言語**: {language}
**動画の種類**: {video_context}
**映像情報の記録**: {include_visual_info}

**動画文字起こし指示事項**:

### 音声の文字起こし
- 話者が複数いる場合は、話者を区別して記録してください（例: 講師：、受講者：）
- 専門用語や固有名詞も可能な限り正確に書き起こしてください
- 音声が不明瞭な場合は[不明瞭]と記載してください
- 背景音や雑音は基本的に無視してください

### 映像情報の記録（{include_visual_info}が有効な場合）
- 画面に表示されるテキストやコードは正確に記録してください
- スライドのタイトルや重要な図表は内容を説明してください
- 講師の動作や指示（画面を指すなど）も記録してください
- 映像情報は[映像: 内容]の形式で記載してください

### コードの記録
コードが画面に表示される場合は、以下の形式で記録してください：
```
講師：このコードを見てください
[映像: 画面にPythonコードが表示]
```python
def example_function():
    return "Hello, World!"
```
```

### 図表・スライドの記録
- スライドのタイトル: [スライド: タイトル名]
- 図表の説明: [図表: 内容の説明]
- 重要な視覚的要素: [映像: 具体的な説明]

### 講師の動作
- 画面を指す: [講師が画面の○○部分を指す]
- 板書: [板書: 書かれた内容]
- デモンストレーション: [デモ: 実行内容]

### 品質保証
- 音声と映像の情報を適切に関連付けてください
- 重要な視覚的情報を見落とさないよう注意してください
- 文字起こしの流れを自然に保ってください

{custom_instructions}

## 使用例
```
音声: "次にこの関数を実行してみます"
画面: Pythonコードとその実行結果が表示
出力: 
講師：次にこの関数を実行してみます
[映像: 画面にPythonコードが表示]
```python
def calculate_sum(a, b):
    return a + b

result = calculate_sum(5, 3)
print(result)  # 出力: 8
```
[映像: コードを実行し、結果として8が表示される]
```

## 注意事項
- 音声の内容を最優先とし、映像情報は補完として使用してください
- コードや重要なテキストは正確に記録してください
- 映像情報が音声と矛盾する場合は、両方を記録して注記してください
- 画面が見えにくい場合は[映像不明瞭]として記録してください
